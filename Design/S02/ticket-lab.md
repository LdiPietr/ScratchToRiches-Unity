# Vintage Lottery playable integration
Open Assets/Scenes/ScratchTicketLab.unity, enter Play Mode, select any ticket, scratch all cells freely. The lab shares the actual scratch and symbol components but has no economy, game manager or save state. Production scene keeps pick limits, economy and skill progression. Native ticket dimensions are different; common fit factor 0.94 in gameplay, 1.0 in lab. Geometry reconstructed from imported art (original manifest was not pushed); 25 hexagons in 3/6/7/6/3 rows. Actual Unity rendering and human scratch timing must be tested. S02 visual reference is unchanged. This integrates the ticket family and background, not the final HUD or localization. Lab is not in build settings.
